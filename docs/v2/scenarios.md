# bitt v2 — the owner's scenarios (the fit list)

Part of the design (`foundation.md`). The `charter` column (#9, approved by the owner 11-03) sorts each row against `charter.md`: **core** is built first, **nice** later, **park** is kept but not built until it earns its place. Home docs written before the rebuild are at the tag `pre-foundation`. Every scenario owner described while designing v2 (2026-10-21 → 2026-10-28), collected from
the design conversations, with what bitt must do. **Use:** before a design change is agreed, walk this list and say for each
scenario it touches whether the design still fits; when a new scenario comes up, add it here in the same commit. Names are synthetic
(a partner product is `product_a`; a spreadsheet is "a labelled xlsx").

Status: **built** (in code, with the slice that built it) · **agreed** (decided, not built) · **proposed** · **open** (not decided)
· **verify** (believed built, not yet checked against a test) · **conflict** (two decisions disagree, or a row says built and the code does not: settle before building). Cleaned 10-30: rows checked against the rebuilt code.
